# Lovjyot Singh

Personal site for Lovjyot Singh, a USICT CSE graduate. One scrolling page, plus a printable résumé at `/resume`.

The page is static HTML, CSS, and a small script. There is no framework, no install, and no build step.

## Run

From this folder:

```bash
python3 -m http.server 4173
```

Open [http://127.0.0.1:4173/](http://127.0.0.1:4173/). The printable résumé is [http://127.0.0.1:4173/resume/](http://127.0.0.1:4173/resume/).

Any static file server works. Opening `index.html` directly also renders the page; clipboard copy is more reliable over `http://localhost`.

## Build

Nothing to compile. `index.html`, `resume/index.html`, `favicon.svg`, `grain.png`, and `fonts/` are the site. `Lovjyot Singh CV.pdf` is the downloadable résumé and is not generated by this page.

## Motion

A fixed overlay follows the pointer by writing `--mx` and `--my` on the document element. A `requestAnimationFrame` loop lerps toward the latest pointer position and stops once it arrives. The overlay is a radial gradient: a soft cobalt halo about 640px across, and a tighter core. It does not use React state, a canvas, or `cursor: none`.

- `(pointer: coarse)`: the follower does not run. The same light drifts slowly with a CSS transform animation.
- `prefers-reduced-motion: reduce`: no lerp and no drift. A static cobalt vignette stays in place.
