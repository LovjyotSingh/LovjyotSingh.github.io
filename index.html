01

OfferForge AI

Full-stack AI mock interview platform

Live (opens in a new tab) Code (opens in a new tab)

Interview loops are role-specific. Seven tracks, including SDE, frontend, backend, data, and product, run as ordered sections such as DSA, system design, OOP, SQL, and behavioral. Each round has a fixed question count and a level: entry, mid, or senior.

A Gemini and OpenRouter pipeline scores each answer on a four-criterion section rubric, then returns strengths, gaps, a model answer, and a hire recommendation. If the model is down, the session falls back to a curated question bank instead of a fake score.

JWT auth sits on MongoDB. The server holds the question flow, so submit, skip, and complete are atomic. A dashboard keeps per-section averages and the score trend. The React and Vite client and the Express API run on Vercel.

Stack React, Vite, Express, MongoDB, JWT, Gemini, OpenRouter, Vercel

02

SyncFlow

Real-time collaborative workspace

Live (opens in a new tab) Code (opens in a new tab)

SyncFlow is a multiplayer block editor in Next.js 16, TypeScript, and BlockNote. Concurrent edits merge through Yjs and broadcast over Socket.io. On every room join the server checks a JWT and admits only the page owner or a collaborator.

Live document state is written to Redis after a 700ms quiet period, with a 30-day TTL. Membership, share tokens, and files live in MongoDB, so a reload restores the page.

Share links rotate. Invites go by email. Presence is live. Member-only uploads are capped at 10 MB on Express. The web app is on Vercel. The Socket.io API runs as a long-lived Node server.

Stack Next.js 16, TypeScript, BlockNote, Yjs, Socket.io, Redis, MongoDB, Express, JWT, Vercel
