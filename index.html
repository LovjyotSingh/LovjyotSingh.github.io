Live · Real-time collaborative workspace

SyncFlow

A multiplayer block editor that runs entirely on Vercel. People edit the same page at once with live cursors, and a sync engine I built from scratch keeps everyone in step without a single server.

  • Serverless sync engine. A custom Yjs provider syncs over plain HTTP instead of WebSockets, polling every 350 ms while anyone types, with one Postgres transaction per round trip.
  • No lost edits. An append-only update log in Postgres (Neon), a 3 s settle window so no concurrent edit is skipped, and background compaction into snapshots. Tested against a real Postgres.
  • Sharing. Signed session cookies, rotatable share links, email invites that wait for sign-up, and files on Vercel Blob.

Live · Full-stack AI mock-interview platform

OfferForge AI

Mock interviews that feel like the real loop: role-specific sections, a fixed number of questions, and feedback graded against a rubric.

  • Structured loops. Rounds for 7 tracks as ordered sections like DSA, system design, OOP, SQL and behavioral, at entry, mid or senior level.
  • Rubric grading. A Gemini and OpenRouter pipeline scores each answer on 4 criteria and returns strengths, gaps, a model answer and a hire call.
  • Session integrity. JWT auth, a server-held question flow with atomic submit and skip, and a dashboard of score trends.

          Live · Spreadsheet engine built from scratch
          
Gridline

          
A spreadsheet that runs in the browser, with no spreadsheet or grid library. I wrote the grid, the formula parser and the recalculation engine myself.

          
    
            
  • Virtualized grid. 10,000 rows scroll smoothly because only the cells on screen, about 100 at a time, are in the page.
    • 
            
  • Formula engine. A tokenizer and Pratt parser with Excel's operator rules, 22 functions, and errors like #DIV/0! that flow to every cell that uses them.
    • 
            
  • Dependency graph. An edit recalculates only the cells downstream of it, in order (a topological sort), and loops show #CYCLE!. One change in a 10,000-row column recalculates 2 cells.
