OfferForge AI — Full-stack AI mock interview platform

SyncFlow — Real-time collaborative workspace

syncflow-sss.vercel.app github.com/lovjyotsingh/syncflow

  • Real-time sync: multiplayer block editor in Next.js 16, TypeScript, and BlockNote. Concurrent edits merge through Yjs and broadcast over Socket.io. Server checks a JWT on every room join and admits only the page owner or a collaborator.
  • Persistence: live document state written to Redis after a 700ms quiet period (30-day TTL); membership, share tokens, and files in MongoDB, so a reload restores the page.
  • Sharing and access: rotatable share links, email invites, live presence, and member-only uploads capped at 10 MB on Express. Web app on Vercel; Socket.io API runs as a long-lived Node server.
